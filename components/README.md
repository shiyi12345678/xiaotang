# components · 公共业务组件

全项目共用的 `zn-*` 前缀业务组件（10 个），零图片资源 —— Logo、头像、图标全部由 CSS 与字体图标实现。

| 组件 | 用途 |
| --- | --- |
| zn-avatar | 头像 |
| zn-company-logo | 公司 Logo |
| zn-empty | 空状态占位 |
| zn-job-card | 职位卡片 |
| zn-nav-bar | 顶部导航栏 |
| zn-price | 价格/薪资展示 |
| zn-progress | 进度条 |
| zn-section-header | 区块标题 |
| zn-tab-bar | 底部 Tab 栏 |
| zn-tag | 标签 |
