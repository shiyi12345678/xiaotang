# 网易云课堂 App 设计规范 & 开发约定

> 本文档是本项目所有页面的统一契约。新增页面必须遵守，避免风格分裂。

## 一、整体约定

| 项 | 约定 |
| --- | --- |
| 技术栈 | uni-app（Vue 语法，Options API），**App 端为主**，严格使用 uni-app 组件与 API |
| 数据 | 纯前端 Mock，**不涉及任何后端/网络请求**，全部从 `@/common/mock/index.js` 引入 |
| 图片 | **不使用任何图片资源**。封面用 `zn-cover` 渐变占位，头像用 `zn-avatar` 渐变圆占位 |
| 主题色 | `#4cd964`（见 `uni.scss` 中 `$zn-*` 变量，已全局注入，无需 import） |
| 单位 | 一律使用 `rpx`（状态栏高度等 px 值除外） |
| 导航栏 | 所有页面 `navigationStyle: custom`，统一用 `<zn-nav-bar>` 组件 |
| 底部导航 | 五个主页面（首页/分类/AI助教/学习/我的）必须引入 `<zn-tab-bar current="xxx" />` |
| 标签写法 | 只用 `<view> <text> <image> <scroll-view> <swiper> <swiper-item> <input> <textarea> <button>`，禁止 `div/span/hr/p` |

## 四、编码规则（重要）

1. **模板里不能直接用 import 进来的函数**（Vue 模板只能访问组件实例成员）。需要在模板里用的工具函数，必须在 `methods` 里挂一遍：
   ```js
   import { formatCount, gradientOf } from '@/common/utils/format.js'
   export default {
     methods: { formatCount, gradientOf }
   }
   ```
2. 页面生命周期 `onLoad / onShow / onReady / onPullDownRefresh / onReachBottom / onUnload` 写在组件根选项上（不要写进 `methods`）。
3. 样式统一 `<style lang="scss" scoped>`，只用 `uni.scss` 里的变量与嵌套写法；不使用 `>>>` / `/deep/`。
4. 列表渲染必须带 `:key`。
5. 点击一律用 `@tap`，可点击元素加 `hover-class="zn-hover"`。
6. 需要新 Mock 数据时，**在本页面 `<script>` 顶部用 const 定义**，不要修改 `common/mock/index.js`（多人并行开发，避免冲突）。
7. 页面底部如无 tabBar，用 `zn-nav-bar` 即可；有 tabBar 的页面无需再留白（`zn-tab-bar` 自带占位）。
8. 跳转：普通页 `uni.navigateTo`，返回 `uni.navigateBack`，切 tab 由 `zn-tab-bar` 内部用 `uni.reLaunch` 处理。
